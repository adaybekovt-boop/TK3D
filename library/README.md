# Reference library

`objects/` contains unmodified donor Python copied from the object harvest.
These files are searchable research material, not TK3D runtime modules. The
curated code library remains under `vendor/generator_library/` because existing
adapters and provenance already use that stable path.

There is no separate material harvest in the supplied archives, so TK3D does not
create an empty `materials/` tree or claim material-library support.
